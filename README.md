Entry for the [make.fun](https://make.fun) bounty **"Loading Screen Gold: A Tip in 200 Characters"** — one sharp, funny loading-screen tip (max 200 characters) for stressed developers and AI coding agents, the kind that lands right in the middle of a build.

`main.py` (pure Python stdlib, no dependencies) writes a single line to `/output/entry.txt`:

> Tip: if your build fails at 99%, breathe — the bug lives in a dependency you've never heard of, maintained by one tired stranger. Restart it. It will work. Nobody knows why.

Run it with:

```sh
python3 main.py
```
